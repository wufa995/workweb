# 个人主页助手

一个功能丰富的个人主页，集成了多种实用工具组件。

## 📁 项目结构

```
liulanqi/
├── index.html      # 主页面
├── day.html        # 日历组件
├── num.html        # 记事本组件
├── bg.jpg          # 默认壁纸
├── README.md       # 说明文档
└── .gitignore      # Git 忽略配置
```

## ✨ 功能特性

### 1. 链接管理
- 双击链接直接在浏览器中打开
- 右键点击链接可编辑或删除
- 支持数据持久化（自动保存到浏览器本地存储）

### 2. 日历组件
- 3×7 表格显示周视图
- 支持添加、编辑、删除事件
- 连续事件自动连接显示
- 浮动窗口，可拖拽和调整大小

### 3. 天气组件
- 实时显示天气信息
- 输入城市名后按回车查询天气
- 点击天气图标或温度可跳转到百度搜索详细天气

### 4. 备忘录
- 快速记录临时笔记
- 自动保存，刷新页面不丢失
- 支持换行和多行输入

### 5. 记事本
- 全屏文本编辑器
- 右键切换编辑/查看模式
- 快捷键 `Ctrl+Q` 快速打开/关闭

### 6. 浮动窗口系统
- 所有组件都可拖拽移动
- 支持调整窗口大小
- 自动保存窗口位置和大小

### 7. 层级管理
- 通过右下角菜单点击显示组件时，该组件自动置顶
- 拖拽组件时自动置顶

### 8. 数据导入导出
- 导出所有数据为 JSON 文件
- 导入 JSON 文件恢复数据
- 支持跨浏览器迁移数据

### 9. 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Q` | 打开/关闭记事本 |

## 🚀 快速开始

### 直接使用
1. 下载或克隆项目
2. 直接用浏览器打开 `index.html` 文件
3. 开始使用各个功能组件

### 上传到服务器
将整个项目文件夹上传到你的网站服务器即可使用。

## 📖 使用指南

### 添加链接
1. 右键点击页面空白处
2. 在弹出的输入框中输入链接地址
3. 按回车或点击确定添加

### 编辑链接
1. 右键点击要编辑的链接
2. 选择「编辑」
3. 修改链接地址后按回车保存

### 删除链接
1. 右键点击要删除的链接
2. 选择「删除」即可移除

### 使用日历
1. 点击右下角菜单中的「日历」打开
2. 点击日期格子添加事件
3. 拖拽事件可调整时间范围

### 使用天气
1. 点击右下角菜单中的「天气」打开
2. 在输入框中输入城市名
3. 按回车查询天气
4. 点击天气信息跳转到百度查看详情

### 使用记事本
1. 按 `Ctrl+Q` 或点击菜单中的「记事本」打开
2. 右键点击切换编辑/查看模式

### 导入导出数据
1. 点击右下角菜单中的「导出数据」保存备份
2. 点击「导入数据」选择备份文件恢复
